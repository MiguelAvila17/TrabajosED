Esta animación explica cada línea del programa PRIMER.ASM.

¿Qué es PRIMER.ASM?

Es un programa de ejemplo que muestra la estructura básica de un programa en ensamblador para el procesador 8086 usando Turbo Assembler.

Comentarios

; PRIMER.ASM
; Este programa ilustra...

Todo texto que inicia con punto y coma (;) es un comentario.

Los comentarios sirven para documentar el programa y son ignorados por el ensamblador.

Código de Inicio

ideal
dosseg
model small
stack 256

ideal: Activa el modo ideal.
dosseg: Organiza los segmentos.
model small: Modelo de memoria pequeño.
stack 256: Reserva 256 bytes para la pila.

Constante Simbólica

cte equ 10

La directiva EQU asigna un nombre a una constante.

cte = 10

Segmento de Datos

dataseg

Inicia la sección donde se almacenarán todas las variables del programa.

Variables

codsal db 0
dato1 db ?
dato2 db ?
resul db ?

db significa Define Byte.

codsal → código de salida.
dato1 → primer dato.
dato2 → segundo dato.
resul → resultado.

? significa sin inicializar.

Segmento de Código

codeseg

A partir de aquí se almacenan las instrucciones ejecutables del programa.

Etiqueta Inicio

inicio:

Es una etiqueta que marca el punto donde comenzará la ejecución del programa.

Inicialización de DS

mov ax,@data
mov ds,ax

@data → AX → DS

Se carga la dirección del segmento de datos en el registro DS.

Carga del Primer Valor

mov al,[dato1]

El contenido de dato1 se copia al registro AL.

Suma del Segundo Valor

add al,[dato2]

AL = dato1 + dato2

Suma de la Constante

add al,cte

AL = AL + 10

Guardar Resultado

mov [resul],al

El valor calculado se almacena en la variable resul.

Finalización

salir:

mov ah,04Ch
mov al,[codsal]
int 21h

end inicio

AH=4Ch indica terminar el programa.

INT 21h llama al sistema operativo DOS.

END INICIO marca el final del programa y especifica el punto de inicio.
